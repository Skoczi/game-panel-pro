# MatchBot CSCO 0.6.3

Immutable upstream controller assets and release evidence. `manifest.json` and
`SHA256SUMS.txt` describe the original ESERV ZIP layout, before extraction into
this repository. Source archives live in `runtime/mixqueue/source-bundles/`;
the unchanged agent runtime lives in `runtime/mixqueue/mq_agent.py`.

Installer paths and content hashes are pinned in
`backend/src/services/matchbotRelease.ts`. Locally generated navigation for
the other seven maps remains in `runtime/mixqueue/navigation/0.6.2/`.

Upstream automated evidence is not deployment evidence or acceptance with real
Steam clients. Keep public matchmaking disabled pending that separate review.
